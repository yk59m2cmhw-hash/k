# Ключи от Милана · DEMO-01

«Ключи от Милана» (Keys to Milan) — рабочее название независимой студенческой инициативы. Цель: помочь студентам Bocconi при переезде найти частную комнату и узнать о ней у тех, кто там живёт. Партнёрства с университетом нет. Вторая цель команды — честно документировать свой вклад и результаты ([журнал](docs/log.md)).

> **Сейчас это демонстрация на вымышленных данных.** Демо не проверяет людей и факты, не бронирует комнаты, ничего не отправляет и не оформляет заселение. Вопрос, который пишет зритель, хранится в памяти вкладки и исчезает при перезагрузке.

## Как открыть

Сборка и зависимости не нужны.

- Откройте `demo/index.html` в браузере двойным щелчком.
- Чтобы открыть с телефона в той же сети Wi-Fi, запустите локальный сервер и зайдите на `http://<IP компьютера>:8000`:

```bash
python3 -m http.server 8000 --directory demo
```

Проверки логики и данных (Node.js 18 или новее):

```bash
node --test
```

## Что внутри

| Экран | Что показывает |
|---|---|
| Start | Даты въезда и выезда, предел расходов в месяц «всё включено», роли, чего демо не делает |
| Rooms | 8 вымышленных комнат. Подходящие сверху, неподходящие свёрнуты, у каждой указана причина |
| Room | Кто остаётся, кто съезжает, кто решает; заметка жильца с историей; расходы по строкам с источником и датой; дорога по планировщику и по опыту жильца; даты и договор; что не проверено |
| Ask | Один вопрос остающемуся или съезжающему жильцу и превью того, что увидит получатель. Вопрос сохраняется только на устройстве |
| Your requests | Сохранённые вопросы со статусом: сохранено здесь, не отправлено, не отвечено |

В шапке каждого экрана видны метка **Demo** и состояние отправки: Nothing sent или «1 not sent». Интерфейс на английском, потому что демо показывают студентам Bocconi. Правила фильтров, источники, чек-лист и подсказки для интервью описаны в [docs/demo-01.md](docs/demo-01.md).

## Структура

```
demo/
  index.html     оболочка страницы
  styles.css     стили: светлая и тёмная тема, без веб-шрифтов
  data.js        вымышленные комнаты, люди и заметки

  app.js         экраны и состояние в памяти страницы
tests/

docs/
  brief.md       бриф проекта (публичная версия)
  demo-01.md     спецификация DEMO-01
  log.md         журнал: работа команды и результаты
```

## Границы

- Только частные комнаты. Места в резиденциях Bocconi на 2026/27 передавать нельзя, у партнёрских резиденций свои условия.
- Доступность и условия решает собственник или уполномоченный управляющий. Жильцы делятся опытом.
- Реальное систематическое сведение сторон в Италии требует отдельного разбора модели, даже для бесплатного пилота. До этого используем интервью и демо.
- Прежде чем работать с реальными данными, команда определяет ответственного, основания, доступ, срок хранения и удаление. В репозиторий попадают только обезличенные итоги: он публичный.

Источники, к которым нужно вернуться перед живым запуском, перечислены в [брифе](docs/brief.md#источники).
