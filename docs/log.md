# Журнал: вклад и результаты

Вторая цель команды — честно документировать свой вклад и результаты. Правила журнала взяты из брифа:

- Данные пользователей берутся только из разговоров с реальными людьми. Примеры, составленные основателями, никогда не выдаются за данные пользователей.
- Тесты интерфейса на примерах записываются отдельно от интервью.
- Сюда попадают только обезличенные итоги: без имён, контактов, адресов и подробностей, по которым можно узнать человека. Репозиторий публичный.
- Отказы и то, что не сработало, записываются так же, как успехи.

## Пилот (позже)

Ориентир по брифу: около пяти участников со стороны жилья и десяти ищущих с совпадающим окном. Для каждого случая записываем разговор, решение, состоявшийся просмотр, сообщённое и отдельно подтверждённое заселение, причины отказов и труд команды. Признак работающей традиции: следующий жилец сам повторил действие, когда пришло время.
